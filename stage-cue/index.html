01 / RUN OF SHOW

큐 시트

셀을 직접 편집하거나 Excel에서 여러 셀을 복사해 붙여넣어. 번호를 누르면 해당 곡의 무대가 열려. 빈 파트는 무대에서 흐리게 표시돼.

03 / STAGE INSTRUMENTS

무대 악기

모든 곡에서 쓰는 악기와 보컬 포지션을 관리해. 곡별 담당자는 큐 시트에서 정해.

02 / SIGNAL ROUTING

앰프 패치

위의 적용 범위에 따라 입력마다 연결을 골라. 곡별로 바꾸지 않은 입력은 전체 기본값을 따라가. 앰프 이름과 입력 수는 모든 곡에서 공통이야.
